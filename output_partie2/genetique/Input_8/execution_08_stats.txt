Mutation : echange de deux cases initialement vides dans un meme bloc.

Elitisme : les meilleures grilles passent intactes a chaque generation ordinaire.
Stagnation : population entierement renouvelee ; meilleur resultat global conserve a part.
Une iteration construit et evalue une nouvelle population, renouvellements compris.
La population initiale est la generation 0 ; son evaluation est comprise dans le temps.
